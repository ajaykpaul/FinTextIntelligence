Model pack: shared-xlmr.v4.1
============================

The code archive never carries model weights, because of their size and their licence
terms (below). The trained model ships separately as FinTextIntelligence-model-v4.1.zip,
about 2.2 GB. Its paths mirror the project, so installing it is one unzip into the
project folder.

The registry entries (artifacts/registry/index.json) are in the code archive. v4.1 is
the same ONNX file as v4, plus Arabic sentiment offsets.

Install and run
---------------

    unzip FinTextIntelligence-model-v4.1.zip -d FinTextIntelligence/
    cd FinTextIntelligence
    pip install -e '.[dev,onnx]'
    shasum -a 256 artifacts/onnx/shared-xlmr.v4.onnx    # should match the table above
    fintext --config configs/release_v4.1.toml demo
    fintext --config configs/release_v4.1.toml serve     # http://127.0.0.1:8080/ui

Use configs/release_v4.1.toml, not the default config. It carries v4.1's dev-tuned
thresholds (toxicity 0.645 English and 0.253 Arabic, misleading 0.468). The default
config's thresholds belong to the heuristic backend, and tests/test_release_config.py
fails if the two drift apart.

Inference needs only onnxruntime. The .pt file is for re-scoring
(fintext evaluate artifacts/models/shared-xlmr-20261119-1831), re-exporting, or further
training. That needs the train extra and the training data.
